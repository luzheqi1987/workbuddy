# 每日AI推文任务 - 项目经验沉淀

## 公众号推文规范
- **标点符号**: 中文段落必须使用全角标点（`，`。`：`；`？`！`（）`""`''`),数字小数点和HTML/CSS属性中的半角标点保留
- **标题限制**: 微信公众号标题字节上限为64字节(UTF-8),全角标点每个占3字节
- **格式约定(自包含规范,不依赖任何历史文章文件)**: 每次生成/重排直接按以下版式执行(可先复制最近一篇已确认排版正确的文章做底稿,再对照本规范逐项检查,但规范以本文为准)：
  1. 容器: 白底、最大宽680px居中、行高1.85
  2. 顶部: 1段居中导语, 15px, 色#9ca3af
  3. 每条新闻依次为：
     - 灰分隔线: `<p style="border-top:1px solid #e5e7eb;margin:24px 0 12px;"></p>`
     - 标题行: 17px加粗, 行首彩色圆角方块 `<span style="display:inline-block;width:6px;height:18px;border-radius:2px;background:{色};margin-right:6px;vertical-align:-2px;"></span>`；颜色依次取 #dc2626/#2563eb/#7c3aed/#d97706/#059669（第1~5条各用一种,循环）
     - 标签行: 13px, 色#9ca3af, 如"AI硬件 · 生态并购 · 开源分发"
     - 正文段落: 16px, 色#374151, 两端对齐
  4. "为什么值得关注"段以 `<strong style="color:{与本条标题方块同色}">值得关注：</strong>` 开头
  5. 结尾: 2段总结收束
  **用户要求"重新排版/用之前的排版"时一律套用本规范,禁止渐变分隔条/卡片等自创样式**
- **结尾约定**: 文章末尾不写日期,不加"编辑……"等署名行
- **标题命名**: 不要使用"AI前线日报|日期"这种每天类似的标题,要根据内容提炼有吸引力的标题

## 推送流程
1. 抓取当天AI新闻(AI硬件、AI软件、AI Coding、具身智能等方向,10条左右)
2. 撰写文章(3500-4500字)
3. 生成AI封面图(深色科技风,16:9)
4. 用BeautifulSoup处理半角→全角标点转换(只动文本节点,不动tag和attribute)
5. 推送到公众号草稿箱(微信API)

## 关键工具
- `fix_punct.py`: 批量半角转全角标点的脚本(项目根目录)
- `push_YYYYMMDD.sh`: 每日推送脚本(基于mp-draft-push skill)
- `build_draft_json.py`: 构建草稿JSON（**推送时必须使用**，不可用bash+jq手动拼接，shell转义会损坏HTML）
- `convert_md_to_html.py`: 简单markdown转微信HTML(只对纯markdown生效)

## ⚠️ 推送注意事项
- **JSON构建**: 必须使用 `build_draft_json.py` 进行JSON序列化，因为它用 `json.dump()` 正确处理所有转义。**禁止**用 bash+jq 的 `--arg` 手动拼接——shell变量传递过程中的多层转义会损坏HTML内容，导致公众号后台排版错乱
- **HTML空白符**: `<p>` 标签的 `>` 后面不能有换行再接文字，微信会把换行渲染成一个可见空格。写文章时确保 `<p ...>文字` 紧贴在一起，不要 `<p ...>\n文字`
- **Digest长度限制**: 公众号草稿箱的 digest 字段限制约 200 字节以内，超出会报 `errcode:45004 description size out of limit`。建议 digest 控制在 180-200 字节 (2026-08-10 经验)
- 推送流程正确姿势：`build_draft_json.py` → `create_draft`，参考 `push_20260725.sh`

## 重要环境变量(.env)
- `WECHAT_APPID`: 公众号AppID
- `WECHAT_SECRET`: 公众号Secret
- IP白名单: 当前IP需在「微信公众平台 → 设置与开发 → 基本配置 → IP白名单」中
## 标题字节计算速查(2026-09-06经验)
- 全角冒号"："= 3字节,半角冒号":"= 1字节,中文标题优先全角标点以保持规范
- 中文每字 = 3字节,ASCII = 1字节
- 64字节限制下大约能容纳 标题格式: 12个中文字 + 1个全角冒号 + 4-5组逗号分隔短语(每组2-3中文字或1英文词)
- 长标题务必先用 `python3 -c "print(len('标题'.encode('utf-8')))"` 验证 ≤64再推送
